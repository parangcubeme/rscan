# ddscan

ddscan is a member-based research intelligence platform foundation.

## Current foundation

- Public landing page
- Login UI placeholder
- Development dashboard preview
- Project-oriented information architecture

## Planned modules

1. Member authentication and organization/workspace separation
2. Web research and permitted crawling/API collection
3. Site tracking code issuance and event ingestion
4. Survey creation/import
5. AI insight and reporting
6. Alerts and scheduled summaries

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
